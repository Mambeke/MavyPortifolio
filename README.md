# Mavis Masikati — Data & Financial Analyst Portfolio

**Live Site:** [https://mavis-masikati.pages.dev](https://mavis-masikati.pages.dev)

Personal portfolio and freelance services website for **Mavis Masikati**, a Data & Financial Analyst based in Cape Town, South Africa, working remotely worldwide.

## What's Inside

- **`index.html`** — Zero-dependency, fast single-page portfolio featuring:
  - **About** — Positioning, background (ALX Africa Data Science + ACCA studies), and toolkit
  - **Services** — Fixed-scope offerings (Sales & Profit Analysis, Financial Reporting & Dashboards, Customer & Retention Analytics, Data Clean-up & Audit Readiness)
  - **Projects** — 11 interactive inline-SVG chart previews linking to public Power BI, SQL, Python, and Excel repositories
  - **Blog** — Practical notes on margin analysis, churn/RFM segmentation, and audit-ready spreadsheets
  - **Contact** — Direct enquiry form, email, LinkedIn, GitHub, and WhatsApp quick-chat
- **`assets/mavis.webp`** — Optimised portrait asset

## Local Preview

Open `index.html` directly in any browser, or serve locally:

```bash
python3 -m http.server 8080
```
